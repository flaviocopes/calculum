# Calculum

A SwiftUI macOS app with the 281 calculators from calculum.dev, plus the `calculum` command line tool. The calculators are JavaScript, run in JavaScriptCore. No dependencies.

- `Calculum/CalculumApp.swift`: the app, its window, the Settings scene and the menus (Calculator menu, Find Calculator, Check for Updates).
- `Calculum/Engine.swift`: loads `engine.js` into a `JSContext` and calls `CalculumEngine`. Every call returns JSON, decoded into the types in `Models.swift`.
- `Calculum/Models.swift`: the catalog, a calculator's tool definition, results, charts, and `SavedCalculation`, a saved summary of inputs and result.
- `Calculum/AppModel.swift`: `AppModel`, which holds the sidebar, the search, the country and the open calculator, and `Session`, the open calculator's values, result and charts. Values are kept in the calculator's own units and converted for display.
- `Calculum/Library.swift`: favorites, recents, saved calculations, the last inputs of each calculator and the country, saved to `~/Library/Application Support/Calculum/library.json`.
- `Calculum/ContentView.swift`: the three columns: sidebar, calculator list, detail.
- `Calculum/CalculatorView.swift`: the calculator page, the input fields, and `ResultPanel`, the bright result card.
- `Calculum/SavedView.swift`: Saved, the list of saved calculations and the summary page of one.
- `Calculum/CompareView.swift`: `Comparison`, two saved calculations from the same calculator matched row by row, `Delta`, which reads the change between two values written the same way, and the comparison page.
- `Calculum/Sections.swift`: the charts, examples, method, guide, country notes and sources.
- `Calculum/Theme.swift`: the category colors and symbols, and shared views.
- `Calculum/NumberText.swift`: formatting and reading numbers in any country's format. Shared with the command line tool.
- `Calculum/CommandLineTool.swift`: Install Command Line Tool, which links `/usr/local/bin/calculum` to the copy in the app, with an administrator prompt when needed.
- `CalculumCLI/main.swift`: the `calculum` command. It compiles with `Engine.swift`, `Models.swift` and `NumberText.swift`, and the app embeds it in `Contents/Helpers`.
- `Calculum/SettingsView.swift`: the Settings window.
- `Calculum/AppUpdater.swift`: checks the GitHub releases once a day and installs updates. It's an identical copy of the template in the `mac-app-updater` skill, so change the template and copy it over instead of editing it here.
- `Calculum/AppIcon.icon`: the Icon Composer icon, generated by `scripts/render-icon.swift`.
- `Calculum/Resources/engine.js`: every calculator, bundled from the calculum.dev source by `scripts/build-engine.sh`. Generated, don't edit.
- `engine/entry.js`: the bridge the bundle is built from. It imports the website's modules and exposes `CalculumEngine`.

## Build and run

Requirements: macOS 15 or later, Xcode 26 (the `.icon` needs it).

```bash
scripts/build-release.sh           # universal Release build, Developer ID signed and notarized when the certificate is in the keychain, dist/Calculum-<version>.zip
open build/release/Release/Calculum.app
xcodegen generate                  # after editing project.yml
swift scripts/check-engine.swift   # runs every calculator in JavaScriptCore, US and metric
scripts/test.sh                    # checks AppModel, Session and Library against the engine
scripts/test-cli.sh                # builds the calculum command and checks its output
scripts/build-engine.sh            # rebuilds engine.js from the website, then checks it
swift scripts/render-icon.swift    # after editing the icon
scripts/screenshot.sh              # docs/screenshot-*.png, saved-*.png and compare-*.png, light and dark
swift scripts/render-banner.swift  # docs/banner.png, from the icon and the light screenshot
```

`project.yml` is the source of the Xcode project, so edit it and regenerate instead of changing `project.pbxproj` by hand. The version lives in its `MARKETING_VERSION`.

`scripts/build-engine.sh` needs a checkout of the calculum.dev website with its `node_modules`, at `~/www/calculum.dev` or wherever `CALCULUM_WEB` points.

## Rules

- Formulas live in the website. To fix or add a calculator, change calculum.dev, then run `scripts/build-engine.sh` here. Never edit `engine.js` by hand, and don't reimplement a calculator in Swift.
- `engine/entry.js` is the only contract between the two. If the app needs more from a calculator, add it there as JSON, then decode it in `Models.swift`.
- A saved calculation is a frozen summary: the inputs as shown, the result and its details, as text, plus the raw values for Open in Calculator. Don't recompute what's displayed from the values, because the saved result must not change when the calculator or the country does.
- Keep every user's data in `library.json`, and keep it out of the repo, the screenshots and anything published. `scripts/screenshot.sh` and `scripts/test.sh` use demo data in memory or a temporary folder, never the real file.
- Versions follow semver: a minor release (1.1.0) for new features, a point release (1.0.1) for bug fixes. Bump `CURRENT_PROJECT_VERSION` by one with every release.
- The updater trusts the GitHub release. Every release needs its `vX.Y.Z` tag, the zip from `scripts/build-release.sh` attached, and a `MARKETING_VERSION` that matches the tag, or the app refuses the update.
- Verify UI changes by building the app and opening it, or with `scripts/screenshot.sh`. Run `scripts/test.sh` after changing the models.
- Releases are signed with Flavio's Developer ID (team `DGFKNTAG99`) with the hardened runtime, and notarized inside `scripts/build-release.sh`. It needs the certificate in the keychain and a notarytool keychain profile named `notary`. CI and forks have no certificate, so the script keeps the ad-hoc signature from Xcode. Every release gets a section in `CHANGELOG.md`, newest first, when that file exists.
